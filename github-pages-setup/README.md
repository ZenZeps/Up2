# Up2 Invite Redirect

This creates a simple redirect page for Up2 app invites.

## Setup Instructions:

1. Create a new GitHub repository called `up2-invites`
2. Upload the `index.html` file to it
3. Enable GitHub Pages in the repository settings
4. Update the `generateInviteLink` function to use your GitHub Pages URL

## Files:
- `index.html` - The redirect page that tries to open the Up2 app
